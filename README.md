# Overclock Redline — Releases

App de menu bar / system tray que monitora em tempo real o uso das assinaturas
de AI (Claude, Codex, Grok, Kimi): % por janela de rate limit, cronômetro até o
reset e o Retrospecto (dashboard de aproveitamento). Exclusivo do plano Ultra.

**Downloads:** veja as [Releases](https://github.com/ustoppble/overclock-redline/releases)
ou baixe pelo site: https://overclock.sh/app/download

| Plataforma | Asset |
|---|---|
| macOS (14+, assinado e notarizado) | `Redline.dmg` (tags `v*`) |
| Windows (instalador) | `redline-setup-{amd64,arm64}.exe` (tags `win-v*`) |
| Linux | `redline-linux-{amd64,arm64}` (tags `linux-v*`) |

O código-fonte é mantido em repositório privado. Este repositório serve apenas
as releases — os apps instalados verificam atualizações aqui.
